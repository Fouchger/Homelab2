## 🎯 Release summary

This release improves Controlplane security and reliability with automated Proxmox API and SSH identity management, restricted bootstrap access, and safer credential handling. It also strengthens monitoring by detecting incomplete Prometheus, Grafana, Loki, and Alloy deployments, fixes the upgrade-complete window so it closes correctly without leaving stale job URLs behind, and improves release validation and release-note accuracy.
