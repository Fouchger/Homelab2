## 🎯 Release summary

They add Technitium DNS provisioning, encrypted MikroTik router backup and confirmed restore, least-privilege RouterOS setup guidance using Controlplane’s live-discovered address, stable VLAN 30 addresses for monitoring services, and safeguards that connect monitoring dependencies only after configuration succeeds. They also add WSL provisioning for Python 3.14, uv, PostgreSQL 18, Task, GitHub CLI and PowerShell; improve CI, migration and Ansible validation; and prevent development files from entering runtime packages or causing tests to hang. Technitium and RouterOS integration are not yet validated against real hardware.
