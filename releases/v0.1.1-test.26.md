## 🎯 Release summary

The apt-cache cleanup added to the common role (rm -rf /var/lib/apt/lists/*) didn't touch the stamp file or directory mtime that ansible.builtin.apt uses to decide whether to honor cache_valid_time. On a host where that check considered the cache "fresh", update_cache was skipped right after the lists were wiped, leaving apt with an empty index and failing with "No package matching 'prometheus-node-exporter' is available." Drop cache_valid_time so the install task always forces a real refresh, consistent with the cleanup that now precedes it.
