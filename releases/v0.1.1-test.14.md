## 🎯 Release summary

Add first-class Controlplane and Proxmox host monitoring, package the Ansible roles/runtime assets, and enforce the Loki → Prometheus → Grafana configuration order. This commit introduces the separate read-only Proxmox monitoring token, Grafana dashboards and data sources, health validation, and Phase 3 acceptance checks for credentials, inventory, idempotent configuration, and service readiness, while updating CI and release packaging to validate the new workflow.
