## 🎯 Release summary

The 2GB rootfs configured for the proxmox_exporter LXC was too small to install common monitoring packages plus the Helper Script's pve_exporter venv, causing "No space left on device" during Configure LXC. Bring it in line with headroom given to the other monitoring LXCs.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/test/install-proxmox.sh | bash -s -- --release v0.1.1-test.24
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.1.1-test.24'
```
