## 🎯 Release summary

test_external_output_collapses_ansi_and_spinner_overwrites asserted "helper: ✔️  Storage space validated" (one space after "helper:"), but the actual persisted line has three: one from _append_monitoring_job_output's "{source}: {line}" template plus two preserved from the source line's own leading whitespace ("  ✔️  Storage space validated"). This is exactly what broke the real CI run just now (AssertionError, exit code 1) -- the underlying ANSI-stripping/spinner-collapse fix committed in 89deac7 was correct; only this test's expected string was wrong. Corrected the assertion to "helper:   ✔️  Storage space validated" (three spaces), verified by tracing the exact string through _normalise_terminal_output and _append_monitoring_job_output's own rendering logic before updating it.
