## 🎯 Release summary

This release improves monitoring reliability by checking the Proxmox exporter against its correct metrics endpoint instead of the Loki health endpoint, ensuring exporter status is reported accurately while preventing unknown monitoring services from being checked against an unrelated endpoint; it also clarifies Ansible root-password variable ownership to reduce naming conflicts without changing password-management behaviour.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/test/install-proxmox.sh | bash -s -- --release v0.1.1-test.23
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.1.1-test.23'
```
