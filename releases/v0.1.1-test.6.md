## 🎯 Release summary

This release corrects the automated Proxmox identity lifecycle by safely creating and repairing the dedicated user, least-privilege role, API token and ACLs; detecting and removing stale Controlplane-managed credentials from earlier installations; and updating token rotation to create, authorise and verify the replacement before revoking the previous ACL and deleting the old token. It also protects unrelated Proxmox identities, improves clean-install recovery, strengthens failure rollback and orphan-token cleanup, and adds comprehensive regression coverage for setup, rotation, rollback and stale ACL scenarios.
