## 🎯 Release summary

This release improves Controlplane monitoring diagnostics by adding complete, downloadable logs for monitoring jobs and Phase 3 acceptance checks, resolving broken History log links for both existing and new events. It also installs Ansible Core automatically through the managed application environment, ensuring monitoring services can be installed or reconfigured after a Controlplane upgrade without manual package installation.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/test/install-proxmox.sh | bash -s -- --release v0.1.1-test.5
```

### Windows WSL

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.1.1-test.5'
```
