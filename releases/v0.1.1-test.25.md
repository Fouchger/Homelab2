## 🎯 Release summary

_installed_service_version's commands dict covered prometheus/grafana/loki only. Every proxmox_exporter configuration job reached this step after a fully successful Ansible run and health check, then failed with an uncaught KeyError ("FAILED: 'proxmox_exporter'") because the service had no matching command. Read the installed version from the Helper Script's pve_exporter venv instead, and add a regression test asserting every SERVICES entry has a version-check command.
