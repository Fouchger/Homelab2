## 🎯 Release summary

Reworked Phase 3 monitoring infrastructure into a controlled creation-first workflow that runs the official Proxmox VE Helper Scripts directly on the Proxmox server to create the Prometheus, Grafana and Loki LXCs. Each service now follows a clear Configuration → Create LXC → Configure LXC → View log sequence, with Ansible configuration reserved for the next development round. The release also automatically installs both the Proxmox root and Controlplane managed-LXC SSH public keys, preserves existing authorised keys, captures live helper-script output in downloadable Controlplane logs, retains a second log on Proxmox, and removes the unused Ansible runtime dependency and premature monitoring acceptance processing.
