## 🎯 Release summary

This release closes a login-throttle gap that let an attacker keep guessing multi-factor codes indefinitely once they had a valid password, since the account lockout was being cleared before MFA verification actually succeeded; adds pre-restart configuration validation for Grafana alongside Prometheus's existing check, and ensures both services' config files are owned by their own service account rather than root; extends the public release pipeline's secret scan to cover the README and both installer script templates (not just NOTICE.md) with a case-insensitive check for credential-shaped filenames; rebuilds the Proxmox syslog firewall rules from a clean slate on every Ansible run instead of only adding to them, so a changed or removed Proxmox host no longer leaves a stale allow rule in place; fixes a bug where a failed container file transfer could leave a temporary archive orphaned on disk indefinitely; and cleans up several smaller inconsistencies, including a stale CHANGELOG entry, a missing WSL platform identifier in the example environment files, gaps in the CI required-file inventory, and Ansible YAML lines that exceeded the lint line-length limit.
