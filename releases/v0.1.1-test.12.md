## 🎯 Release summary

Monitoring helper profiles were still defaulting to Ubuntu 24.04 templates even though the upstream Community Scripts support Debian 13. This change updates the default monitoring templates, adds a migration for existing profiles, and ensures helper script environment generation falls back to supported Debian values when older Ubuntu templates remain in the database.  It also refreshes the monitoring configuration UI to load OS choices from the Proxmox appliance catalogue, display friendly template names while storing the full Proxmox template filename, and surfaces catalogue refresh warnings without breaking saved settings.
