## 🎯 Release summary

Corrected Proxmox managed API access by adding the propagated `SDN.Use` privilege required for Linux bridges, SDN vnets and VLAN-tagged LXC networking, while retaining the existing least-privilege permissions for container creation, storage, power management and monitoring. API status validation now confirms both token authentication and the complete effective privilege set, allowing missing permissions to be detected before provisioning begins. Regression tests and supporting documentation were also updated to cover the managed role, automated verification and safe token lifecycle.
