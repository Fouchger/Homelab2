## 🎯 Release summary

This release improves operational resilience and installation clarity by adding a watchdog that detects stalled background jobs and safely restarts only verified Controlplane worker processes, persisting Proxmox syslog firewall restrictions across reboots, and introducing consistent colour-coded installer status messages that remain plain when output is redirected to logs. It also completes release-security verification for pinned GitHub Actions and updates the project’s follow-up review records.
