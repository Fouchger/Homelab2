## 🎯 Release summary

This release improves Controlplane’s monitoring LXC provisioning by adding a Proxmox-synchronised operating-system catalogue, restricting selections to supported Debian and Alpine system templates, excluding TurnKey images, clearly distinguishing duplicate builds by version and architecture, and retaining the complete template filename for helper-script execution. It also strengthens release-management workflows, documentation, validation and automated tests, with all Linux/package checks and 53 Django tests passing.
