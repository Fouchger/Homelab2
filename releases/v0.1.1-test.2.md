## 🎯 Release summary

Phase 3 introduces Controlplane-managed infrastructure provisioning, configuration and monitoring through the web application. It adds secure Proxmox API integration with SSH retained only for bootstrap and recovery, dedicated Proxmox user/role/token management with rotation, per-application LXC configuration for Prometheus, Grafana and Loki, button-driven LXC deployment, and Ansible-based desired-state configuration to keep all managed servers consistent. The phase also adds infrastructure inventory, Prometheus metrics collection from Proxmox, Controlplane and monitoring LXCs, centralised logging through Loki and Grafana Alloy, Grafana data sources and dashboards, operational alerting with History integration, health/status views in Controlplane, and a Phase 3 acceptance runner that validates provisioning, configuration idempotency, monitoring targets, log ingestion, alert lifecycle and overall platform readiness.
