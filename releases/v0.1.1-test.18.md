## 🎯 Release summary

This release adds secure, administrator-controlled LXC destruction for every Controlplane-managed monitoring container, including CTID confirmation, live identity and tag validation, automatic removal of the Proxmox protection flag, orderly shutdown, forced deletion, inventory cleanup and complete History logging. The Infrastructure interface has also been refined with consistent theme-aware button colours: primary actions use each theme’s main accent, secondary actions use its lighter accent, destructive actions are red, and unavailable controls are clearly disabled with explanatory tooltips. Supporting migrations, documentation and automated tests are included, with the complete repository and Django test suites passing.
