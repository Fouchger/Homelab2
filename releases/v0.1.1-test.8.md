## 🎯 Release summary

Capture full Proxmox API task output, SSH and Ansible stdout/stderr into monitoring job logs with credential and private-key redaction. Record Proxmox UPIDs and API outcomes for traceability and treat Proxmox `WARNINGS: n` exit statuses as completed-with-warnings. Implement _redact_monitoring_output and _append_monitoring_job_output for safe, line-oriented persistence; propagate an optional job parameter through Proxmox, SSH and Ansible helper functions. Add UI live-refresh of full logs (views + template) and unit tests covering capture and redaction.  Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>
