## 🎯 Release summary

Bundle and validate a release-managed ansible-core runtime and packaged roles. Adds ansible/ansible.cfg and runtime discovery/repair in phase3 (_managed_ansible_executable, _ensure_ansible_runtime, layout checks, uv-based repair). Worker and installer support: systemd env vars for Ansible, installer pushes runtime to /opt/controlplane/app/runtime/ansible and validates ansible-playbook/ansible-galaxy versions and playbook syntax. Runtime-aware readiness checks and upgrade-time validation were added. Tests and documentation updated to cover the new managed Ansible behavior and release artifacts.
