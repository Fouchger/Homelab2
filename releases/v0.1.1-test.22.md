## 🎯 Release summary

Add a fourth managed monitoring LXC (Proxmox Exporter) provisioned via its own Helper Script, retire the old in-Prometheus exporter, and add root/SSH password support to all four monitoring LXCs with Fernet-encrypted, audited reveal. Ship Grafana Alloy and node_exporter fleet-wide with an apt-upgrade-pending metric. Add a live, Prometheus-backed Dashboard and a Services launcher page. Fixes a Grafana dashboard-provisioning path bug that broke every dashboard copy in production, and corrects the Phase 2 test/doc guardrails that still expected the old placeholder dashboard.
