## 🎯 Release summary

This release introduces automated Proxmox API credential management, secure token rotation, managed SSH identities and official Proxmox VE Helper Script creation for the Prometheus, Grafana and Loki LXCs, with clearer task sequencing and complete operational logs available from the Infrastructure page. It also restores the core Controlplane installer to its established Phase 2 responsibilities by moving Proxmox SSH setup into the explicit configuration workflow and deferring Ansible, Node Exporter, Alloy and monitoring-service configuration to the next implementation phase, supported by expanded installation, packaging, CI and Django regression testing.

## ⚡ One-line installation

### Proxmox VE

```bash
curl -fsSL https://raw.githubusercontent.com/Fouchger/Homelab/test/install-proxmox.sh | bash -s -- --release v0.1.1-test.10
```

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://raw.githubusercontent.com/Fouchger/Homelab/test/install-wsl.ps1'))) -Release 'v0.1.1-test.10'
```
